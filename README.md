# 🚀 Django Learning Journey

Welcome to my repository! This project represents my hands-on journey learning web development with **Python** and **Django**. 

I created this repository to apply foundational concepts directly into code, explore full-stack development patterns, and build a strong backend engineering foundation from the ground up.

---

## 🎯 What I Learned & Practiced

- **MVT Architecture:** Model-View-Template pattern and requests flow.
- **Routing & Controllers:** Crafting clean URL configurations and handling HTTP requests.
- **Database & ORM:** Designing models, running migrations, and querying data.
- **Authentication:** Managing users, registration, logins, and access control.
- **Backend Fundamentals:** Project setup, environment management, and best practices.
